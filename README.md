# EasyMix - Downloads

## Instalar

Abra a pagina Releases.
Baixe o EasyMix-Setup-<versao>.exe mais recente.
Execute e siga o assistente (instala o VST3 em `C:\Program Files\Common Files\VST3`).
Abra a DAW, faca um rescan de plugins e carregue EasyMix no canal Master.

## Requisitos

Windows 10/11, 64 bits.
DAW com suporte a VST3.

## Como usar

Com o plugin no Master, abra o editor: ele mostra um QR Code + URL. Aponte a
camera do celular para o QR (celular na mesma rede Wi-Fi do PC) e toque em
"Ouvir minha mix" -- sem instalar app nenhum.

Mais detalhes, limitacoes e roteiro de fases estao no README do projeto principal.
