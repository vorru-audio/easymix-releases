# EasyMix — Downloads

Repositório **público só de binários** do EasyMix by Vorru Audio.

- O **código-fonte** fica no repositório privado (não é público de propósito).
- Aqui sai apenas o instalador, publicado como **Release**.

## Instalar

1. Abra a página [Releases](https://github.com/vorru-audio/easymix-releases/releases).
2. Baixe o `EasyMix-Setup-<versão>.exe` mais recente.
3. Execute e siga o assistente (instala o VST3 em `C:\Program Files\Common Files\VST3`).
4. Abra a DAW, faça um *rescan* de plugins e carregue **EasyMix** no canal Master.

## Requisitos

- Windows 10/11, 64 bits.
- DAW com suporte a VST3.

## Como usar

Com o plugin no Master, abra o editor: ele mostra um **QR Code** + URL.
Aponte a câmera do celular para o QR (celular na mesma rede Wi-Fi do PC)
e toque em **"Ouvir minha mix"** — sem instalar app nenhum.

Mais detalhes, limitações e roteiro de fases estão no README do projeto principal.
